**Network of Wallets — Email System**

**Venmo x PayPal**

**Overview**
HTML email system designed for the launch of cross-platform payments between PayPal and Venmo.
Focused on turning a complex feature into a clear, scalable, and conversion-driven experience.

**Problem**
Users didn’t understand the feature or how to use it, creating low awareness and adoption.

**Solution**
UX-first email design based on:
One idea per block
Scan-first layout
Strong CTAs
Trust-driven messaging

**Responsive HTML**
Light & dark mode
Modular components
Cross-client compatible

**Usage**
Clone → Edit → Test → Deploy
